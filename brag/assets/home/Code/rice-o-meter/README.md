# rice-o-meter

Measures how ricey your `hyprland.conf` is.

```sh
cargo run -- ~/.config/hypr/hyprland.conf
python rice.py hyprland.conf    # same, slower
```

| score | meaning |
|-------|---------|
| < 20  | stock. respect. |
| < 100 | healthy hobby |
| > 100 | see a sunbeam |

Contributions welcome, but gaps_in stays at 5.
