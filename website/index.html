Install it tonight

Qt 6 on Wayland. Pick the package your system already trusts.

yay -S hyprfm-git
flatpak remote-add --user --if-not-exists \
  flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --user --if-not-exists \
  hyprfm https://flatpak.hyprfm.soyebjim.me/hyprfm.flatpakrepo
flatpak install --user hyprfm io.github.soyeb_jim285.HyprFM
chmod +x HyprFM-*-x86_64.AppImage
./HyprFM-*-x86_64.AppImage

Download the AppImage from the latest release. It bundles Qt.

nix run github:soyeb-jim285/hyprfm
git clone --recursive https://github.com/soyeb-jim285/hyprfm.git
cd hyprfm
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
